# 🤖 Python AI Assistant (Termux Ready)

Простой и легкий консольный ИИ-ассистент, который работает прямо в терминале (Termux/Linux). Использует бесплатную модель через OpenRouter API.

## 🚀 Возможности
- Общение с нейросетью прямо в консоли.
- Не требует мощного железа (работает даже на телефоне).
- Использует бесплатную модель `nvidia/nemotron-3.5-super-vl:free`.

## 🛠 Установка и запуск

1. Установите Python (если еще не установлен).
2. Установите зависимости:
